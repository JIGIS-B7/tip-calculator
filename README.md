# Tip Calculator

A simple command-line tool to calculate tips and split bills.

## Usage

```bash
python tip.py
```

Enter the bill amount, tip percentage, and number of people — the tool calculates the tip, total, and amount per person.

## Example

```
=== Trinkgeldrechner ===
Rechnungsbetrag (€): 80
Trinkgeld (%): 15
Anzahl Personen: 4

Trinkgeld:      €12.00
Gesamt:         €92.00
Pro Person:     €23.00
```
